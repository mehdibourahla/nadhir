# M6 New-Source Gate & National-Sources-Only Compliance Checklist

This runbook documents the Nadhir **M6 New-Source Gate** (criteria M6-1 through M6-7) and verifies compliance for all **9 Track 4 worker sources** (4 M4A + 5 M4B) plus continuity of the existing real-time `emsc` M2+ and `fci` WFS contracts on `cloudflare`.

All criteria below are continuously enforced by `src/lib/__tests__/m6-source-gate.test.ts`, `src/lib/__tests__/m4b-scientific-sources.test.ts`, `supabase/tests/m4a_rainfall_tariki_craag.test.sql`, and `supabase/tests/m4b_scientific_sources.test.sql`.

## 4. PR #31 Exclusion Attestation

Per `GAPS.md:591-600` and `docs/source-successors.md:3-8`, the following superseded PR #31 artifacts are **permanently excluded** from Nadhir runtime ingestion and explicitly rejected by M4B parsers and database constraints:

1. **MTG FCI L1c polling (`EO:EUM:DAT:0665`)**: Hard rejected in `src/lib/ingest/mtg-fci-push.ts` and in SQL `public.record_mtg_fci_push_delivery(...)`. Only L2P FRP (`EO:EUM:DAT:0662`) is accepted.
2. **Unsupported `detections.source = 'eumetsat_fci'`**: Hard rejected in `src/lib/ingest/mtg-fci-push.ts` and blocked by unchanged `detections_source_check` (`'firms'`, `'fci'`, `'s3'`).
3. **Terrain-rotated shared downwind bearing (`spread_bearing_deg` / `rotated_bearing`)**: Rejected by parser guards; absent from all Track 4 runtime code.
4. **Hard-coded burn circles (`burn_circle_m` / `burn_radius_m` / `Point` geometries in GWIS)**: Rejected in `src/lib/ingest/gwis.ts` and blocked by `gwis_burned_areas` DB `CHECK` requiring `Polygon` or `MultiPolygon`.
5. **Invented fuel-recovery curves (`fuel_recovery_curve` / `recovery_factor`)**: Rejected in `src/lib/ingest/gwis.ts` and `src/lib/ingest/clms.ts`.
6. **Logistic calibration (`logistic_calibration` / `calibrated_probability`)**: Rejected in `src/lib/ingest/mtg-fci-push.ts`, `src/lib/ingest/gwis.ts`, and `src/lib/ingest/clms.ts`.

## 5. Architectural & Security Attestations

- **ADR-0001 (Zero PostGIS)**: All Track 4 tables (`rainfall_observations`, `lightning_observations`, `gwis_burned_areas`, `clms_land_indices`, `ghsl_exposure`, `mtg_fci_push_deliveries`) store plain WGS84 `lat`/`lon` double-precision coordinates and GeoJSON `jsonb` polygons only. Distance resolution uses `haversineKm` from `src/lib/nadhir.ts`. Zero PostGIS types or extensions exist in Track 4 migrations.
- **ADR-0002 (Honesty & Attribution)**: Every persisted row carries explicit source attribution and timestamps. Satellite detections, lightning flashes, GWIS thermal burned-area estimates, CLMS NDVI/SWI indices, and GHSL modeled residents never claim official fire confirmation, optical burn scars, calibrated fuel availability, or live occupancy.
- **Pre-Filter Freshness Watermark (`GAPS.md:656-663`, pre-rebase `792-799`)**: Every spatial Track 4 adapter records `upstreamPublishedAt` (or `publishedAt` for reference `ghsl_population`) before applying watch-area, Algeria bbox, dry-cell, or QA filters, ensuring quiet windows advance checkpoints cleanly without calling upsert.
- **SQL Function & Table Least-Privilege (`GAPS.md:643-648`)**: Every Track 4 `SECURITY DEFINER` function (`write_text_source`, `apply_craag_earthquake_attribution`, `record_mtg_fci_push_delivery`) sets `search_path = ''` and executes explicit `REVOKE ALL ON FUNCTION ... FROM PUBLIC, anon, authenticated; GRANT EXECUTE ... TO service_role;`. Public scientific tables grant read-only `SELECT` to `anon` and `authenticated`; operational push audit table `mtg_fci_push_deliveries` revokes all privileges from `public`, `anon`, and `authenticated` and restricts access exclusively to `service_role`.
- **Cloudflare Workers / Web Standard Runtime**: All Track 4 ingest modules under `src/lib/ingest/` and `src/lib/text-sources/tariki*` contain zero `node:` imports and zero `Buffer.` calls, relying exclusively on Web Standard APIs (`ArrayBuffer`, `Uint8Array`, `TextDecoder`, `AbortSignal.timeout`) and `geotiff` `fromArrayBuffer`.
